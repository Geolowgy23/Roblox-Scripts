# 🎮 Roblox Scripts Collection

A modular collection of Lua and Luau scripts, utilities, and gameplay modifications for Roblox.

---

## 📂 Features & Categories

- **Combat & Targeting:** Aimbot tools, target tracking, and weapon automation.
- **Movement & Navigation:** Teleportation mechanics (Click-to-TP, Gun TP) and anti-teleport safeguards.
- **Visuals & Overlays:** ESP (Extra Sensory Perception) and player tracking utilities.
- **Character & Controls:** Custom movement controls, invisibility mechanics, animations, and emotes.
- **Game-Specific Utilities:** Custom automation scripts for select Roblox titles (e.g., Entrenched, Prison Life, Grow Garden).
- **Developer Tools:** Remote instance inspection (Dex Explorer) and core execution helpers.

---

## 🚀 How to Use

1. Browse the repository and select the script suited for your needs.
2. Open the file and copy the code using the **Raw** button.
3. Run the script in your preferred testing environment or Roblox Studio session.
